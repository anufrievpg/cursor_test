# Карта процессов сотрудника ЭНКО

Интерактивная иерархическая карта тендерных процессов ГК «ЭНКО» на **HTML5 `<canvas>`**.

## Файл

Откройте в браузере:

[`enco-employee-process-map.html`](./enco-employee-process-map.html)

## Canvas

Центральная карта рисуется через элемент `<canvas id="mapCanvas">`:
- узлы, связи, handoff-стрелки, сетка и легенда — `CanvasRenderingContext2D`
- картинки ролей — `drawImage`
- клики — hit-testing по прямоугольникам узлов
- pan / zoom — world-transform

HTML самодостаточный: логотип и все иллюстрации (включая корневую) встроены как `data:` URI, поэтому картинки не пропадают при открытии файла без папки `assets`.

## Роли

- **Сквозной процесс тендера** — end-to-end от потребности до договора
- **Инициатор тендера** — подготовка, публикация, приём КП
- **Расчетчик** — эталонная цена и сравнение предложений
- **Служба безопасности** — due diligence и допуск участников
- **Тендерный комитет** — решение, протокол, контроль исполнения

## Инструкция по этапам и шагам

В панели деталей каждый этап и каждый шаг процесса дополнены **тематическими блоками**:
- Цель, Действия, Документы, Системы
- Контроль / Чек-лист, Риски, Правила, Передача

Блоки прикреплены к сквозному процессу и ко всем ролям: Инициатор, Расчетчик, СБ, Тендерный комитет.

## Возможности

- Дерево слева + HTML5 Canvas по центру + панель деталей справа
- Картинки, шаги, входы/выходы, системы, SLA, RACI
- Фильтры по ролям, поиск, pan/zoom
- Фирменные цвета ЭНКО (`#122A4B`, `#0072BC`)

## АСТ-Альфа · модуль «Тендеры»

Карта уточнена по **Инструкции пользователя Заказчика** модуля «Тендеры» портала «АСТ-Альфа» (релиз 3.12.0).

- В блоках этапов и шагов — конкретные действия, статусы, разрешения и экраны АСТ
- К блокам прикреплены **сканы страниц инструкции** (компактное превью; крупный просмотр открывается в соседней вкладке справа)
- Правая панель расширена для читаемости текстовых блоков
- Исходные PDF: [`docs/`](./docs/)
- Сканы JPG: [`scans/`](./scans/)

Статусы тендера в АСТ: `Черновик` → `Сформирован` → `Открыт` → `Подведение итогов` → `Окончен`.
