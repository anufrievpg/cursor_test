# Карта процессов сотрудника ЭНКО

Интерактивная иерархическая Canvas-карта тендерных процессов ГК «ЭНКО» с выгрузкой в HTML.

## Файл

Откройте в браузере:

[`enco-employee-process-map.html`](./enco-employee-process-map.html)

## Роли

- **Сквозной процесс тендера** — end-to-end от потребности до договора
- **Инициатор тендера** — подготовка, публикация, приём КП
- **Расчетчик** — эталонная цена и сравнение предложений
- **Служба безопасности** — due diligence и допуск участников
- **Тендерный комитет** — решение, протокол, контроль исполнения

## Возможности

- Кликабельное дерево слева и Canvas-карта по центру
- Панель деталей: картинка, шаги, входы/выходы, системы, SLA, RACI
- Фильтры по ролям, поиск, pan/zoom
- Фирменные цвета ЭНКО (`#122A4B`, `#0072BC`)
