# ОБИТИ · ЭНКО

Интерактивное описание департамента **бизнес-инноваций и технологической интеграции (ОБИТИ)** в корпоративном стиле ГК «ЭНКО» — по тому же визуальному языку, что и [Карта процессов сотрудника](../enco-process-map/).

## Открыть

[`enco-obiti-department.html`](./enco-obiti-department.html)

Файл самодостаточный: логотип ЭНКО встроен как `data:` URI. Кнопка **⬇ Скачать** в шапке выгружает копию страницы.

### iPhone / iPad

iOS **не открывает локальный `.html` как обычный сайт**: «Файлы» / Quick Look часто дают пустой или «мёртвый» экран (скрипты и интерактив ограничены).

Рабочие варианты:
1. Открыть файл **по ссылке в Safari** (с хостинга / GitHub Pages / внутреннего портала), а не из приложения «Файлы».
2. В «Файлы» → файл → **Поделиться** → **Открыть в Safari** (если пункт есть).
3. Для офлайн-просмотра — приложение вроде Html Preview из App Store.

На телефоне вёрстка рассчитана на обычный скролл; desktop-оболочка с `overflow: hidden` включается только на больших экранах с мышью.
