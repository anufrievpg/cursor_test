# ОБИТИ · ЭНКО

Интерактивное описание департамента **бизнес-инноваций и технологической интеграции (ОБИТИ)** в корпоративном стиле ГК «ЭНКО» — по тому же визуальному языку, что и [Карта процессов сотрудника](../enco-process-map/).

## Открыть

[`enco-obiti-department.html`](./enco-obiti-department.html)

Файл самодостаточный: логотип ЭНКО встроен как `data:` URI. Кнопка **⬇ Скачать** в шапке выгружает копию страницы.

1. Миссия и позиционирование для трёх аудиторий  
2. Расшифровка **О-БИ-ТИ**

4. Манифест из 5 принципов

6. Интерактивная оргструктура (10 человек, 4 блока) с профилями

9. Матрица RACI по 11 сквозным процессам + регламент взаимодействия блоков
