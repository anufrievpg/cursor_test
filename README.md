# Миграция файлов 1С:ДО → Nextcloud

Набор инструментов для переноса документов из **1С:Документооборот** (ДО 2.x / 3.x) в **Nextcloud** с сохранением:

- иерархии папок
- всех версий файлов
- метаданных (автор, даты, описание, комментарии к версиям)
- пометок на удаление

---

## Структура репозитория

```
1c/
  export_do_files.bsl         — Внешняя обработка 1С: выгрузка файлов на диск
python/
  upload_to_nextcloud.py      — Python-скрипт: загрузка в Nextcloud
  requirements.txt
```

---

## Шаг 1 — Выгрузка из 1С:ДО

### Что делает обработка

- Обходит все файлы справочника `ФайлыДокументов` (или `Файлы` в ДО 3.x).
- Для каждого файла выгружает **все версии** из регистра `ВерсииФайлов`.
- Рядом с каждым файлом/версией создаёт `<имя>.meta.json` с метаданными.
- Сохраняет сводный `_export_index.json` и лог `_export_log_*.txt`.

### Структура каталога на диске

```
C:\Export_1CDO\
  _export_index.json
  _export_log_20240101_120000.txt
  Входящие\
    Договор_2023.docx
    Договор_2023.docx.meta.json
    _versions\
      Договор_2023.v001.docx
      Договор_2023.v001.docx.meta.json
      Договор_2023.v002.docx
      Договор_2023.v002.docx.meta.json
  Исходящие\
    ...
```

### Пример `.meta.json`

```json
{
  "source_system": "1C:DO",
  "name": "Договор_2023",
  "extension": "docx",
  "description": "Договор с ООО Ромашка",
  "author": "Иванов Иван",
  "created_at": "2023-03-15T10:00:00",
  "modified_at": "2023-11-20T14:32:00",
  "folder": "Входящие",
  "guid_1c": "a1b2c3d4-...",
  "is_deleted": false,
  "version": {
    "number": 2,
    "total": 2,
    "is_current": true,
    "size_bytes": 45312,
    "comment": "Финальная редакция",
    "version_author": "Петров Пётр",
    "version_date": "2023-11-20T14:32:00"
  }
}
```

### Подключение обработки

1. Откройте 1С:Предприятие с базой 1С:ДО.
2. `Файл → Открыть` → выберите `1c/export_do_files.bsl`  
   (или добавьте код в новую внешнюю обработку через конфигуратор).
3. В самом конце файла задайте параметры:

```bsl
КаталогВыгрузки   = "C:\Export_1CDO\";  // путь для выгрузки
ВыгружатьВерсии   = Истина;              // все версии
ВыгружатьУдалённые = Ложь;              // пропускать удалённые
```

4. Запустите процедуру `ВыполнитьВыгрузку()`.

> **Требования к правам:** роль *Полные права* или права на чтение справочников  
> `ФайлыДокументов`, `ПапкиФайлов` и регистра `ВерсииФайлов`.

## Шаг 2 — Загрузка в Nextcloud

### Установка зависимостей

```bash
cd python
pip install -r requirements.txt
```

### Базовый запуск

```bash
python upload_to_nextcloud.py \
    --export-dir /path/to/Export_1CDO \
    --nextcloud-url https://cloud.example.com \
    --username admin \
    --password "ваш_пароль" \
    --remote-dir /1CDO_Migration
```

### Все параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--export-dir` | — | Путь к каталогу выгрузки (обязательно) |
| `--nextcloud-url` | — | URL Nextcloud (обязательно) |
| `--username` | — | Логин (обязательно) |
| `--password` | — | Пароль или app-token (обязательно) |
| `--remote-dir` | `/1CDO_Migration` | Целевая папка в Nextcloud |
| `--no-versions` | выкл | Не загружать старые версии |
| `--no-tags` | выкл | Не назначать теги |
| `--no-comments` | выкл | Не добавлять комментарии к файлам |
| `--no-sidecar` | выкл | Не загружать `.meta.json` рядом с файлом |
| `--threads` | `2` | Число параллельных потоков загрузки |
| `--state-file` | `upload_state.json` | Файл для возобновления прерванной загрузки |
| `--log-file` | `upload.log` | Файл журнала |

### Возобновление прерванной загрузки

Скрипт сохраняет состояние в `upload_state.json`. При повторном запуске с теми же параметрами уже загруженные файлы пропускаются автоматически.

### Что создаётся в Nextcloud

- Зеркальная иерархия папок из 1С:ДО.
- Текущая версия файла в соответствующей папке.
- Старые версии в подпапке `_versions/`.
- `<имя>.meta.json` рядом с каждым файлом.
- **Теги** на файле: `author:Иванов`, `1cdo:Входящие`, `versions:3`.
- **Комментарий** к файлу с исходными метаданными из 1С:ДО.

## Рекомендуемый порядок миграции

1. Сделайте тестовую выгрузку одной папки (ограничьте запрос в обработке условием `И ф.Родитель = &ТестоваяПапка`).
2. Запустите скрипт с `--no-tags --no-comments` для проверки структуры.
3. Убедитесь, что файлы открываются из Nextcloud.
4. Запустите полную миграцию.
5. После проверки удалите `.meta.json` сайдкары если они не нужны.
